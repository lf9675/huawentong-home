# 中二高级华文 · 单元二 ·《猫》

版本：20261020-mao-1；三课时，每课按50分钟安排。

教材依据为2026-10-20用户提供的第37—43页课文与练习、三张教参截图及四张既有漫画。本文改编自郑振铎的《猫》。全部12段逐句核对；四张漫画原样保留，32格通过显示窗口对应段落，原图文件没有改动。

## 教学安排

第一课读第1—4段，认识猫的外形、动作与家人态度；第二课读第5—9段，区分事实与人物判断，理解动作、拟声词及引号；第三课读第10—12段，理解愧疚、首尾呼应，再完成形象情感统整与角色回应。

10组内容拆成17个短问题页，遵从段落顺序；全文综合在第12段之后。保留课本旁注、预习印象表、拟声词两空、阅读放大镜及必做读后说。只增加第6、10段两道标明来源的口头／取证支架，帮助建立事实与判断的区分。第2、5、8、9段后文关系随阅读补全。重点独立书写按1、1、2题安排。

答案依据原文，保留“好像”“似乎”“仿佛”“猜想”的不确定性；结尾未确认猫死亡。漫画第17格说话人及第20格妻子情绪与原文可能产生歧义，教师方案明确以原文为准。开放题允许愤怒、不原谅、宽容等立场，评价理由与证据，不要求原谅。
