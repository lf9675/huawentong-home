# 中二高级华文单元一《把爱说出来》

本课依据2026-10-19用户提供的课文、课本问题、教参截图及三张漫画制作。16段原文保存在`content.js`；三张漫画保持原始文件，通过显示窗口对应30格。没有另造篇章或课后一周小测。

## 教学设计

建议3×50分钟，教师方案另附2×50分钟流程。先读懂女儿、儿子与“我”的表达方式，再解释“我”的犹豫，最后理解母亲歌声与爱的表达。先教师示范、共同取证，再自主比较与开放回应。

|任务|来源|主要证据与活动|
|---|---|---|
|1 女儿的欣赏与儿子的反应|旁注第1段、人物比较基础|第1–4段，点句取证、区分崇拜与表面顺从|
|2 惯用语在语境中|阅读放大镜一|保留原三句，先讲比喻义再选词|
|3 没说出口能说明什么|旁注第4、8段|第1–8段，谨慎推断儿子内心，整合“我”的感受|
|4 感谢为什么变成决定|旁注第10段前半、教参|第9–11段，心理描写、感恩与自省|
|5 为什么迟迟说不出口|旁注第14段|第10–15段，缺乏表达习惯与害羞|
|6 细节怎样突出心情|旁注第15段、教参第3、14段|比较紧张程度，保留“张大眼睛”“破天荒”追问|
|7 用证据比较人物|阅读放大镜三、第10段旁注后半|儿子与女儿、女儿与“我”；自主写特点、证据、解释|
|8 歌声有什么含义|阅读放大镜二、旁注第16段|整合反应与感受，联系第9段，说明主旨|
|9 第一次一定最难吗|教参第12段|说明适用条件，允许有根据的不同看法|
|10 爱需不需要说出来|读后说|必做：立场、理由、例子、回扣；自主书面回应|

儿子拒绝听文章及否定赞美是明示事实；是否爱母亲不可当作已确定的事实。教参相关说法作为可讨论解释，不能替代证据。结尾唱歌支持心情改善、感到爱与安慰，不支持从此完全结束哀伤。外貌/神态名称保留课本口径。开放题允许不同立场，无须披露家庭隐私。
