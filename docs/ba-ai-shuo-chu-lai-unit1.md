# 中二高级华文单元一《把爱说出来》

本课依据2026-10-19用户提供的课文、课本问题、教参截图及三张漫画制作。16段原文保存在`content.js`；三张漫画保持原始文件，通过显示窗口对应30格。没有另造篇章或课后一周小测。

## 教学设计

建议3×50分钟，教师方案另附2×50分钟流程。先读懂女儿、儿子与“我”的表达方式，再解释“我”的犹豫，最后理解母亲歌声与爱的表达。先教师示范、共同取证，再自主比较与开放回应。

|段落顺序|来源|安排|
|---|---|---|
|同一件事，不同反应|课本旁注 第1、2段|找出女儿与儿子的语言和行动，再比较。|
|第三段：张大眼睛|教参 第3段|先口头回答，再查看讲评。|
|第四段：儿子爱“我”吗|课本旁注 第4段|结合儿子的表现，说明你的看法。|
|第八段：“我”的感受|课本旁注 第8段|结合前文，概括“我”的感受。|
|第九段：母亲的情况|教参 第9段|先口头回答，再查看讲评。|
|第十段：感激与反思|课本旁注 第10段|找出反思的原句，再解释人物特点。|
|第十一段：下定决心|教参 第11段|先口头回答，再查看讲评。|
|第十二段：第一次一定最难吗|课本旁注 第12段|说明你的立场和理由。|
|惯用语在语境中|课本 阅读放大镜一|读到第十二段后，完成课本的惯用语练习。|
|第十四段：破天荒|教参补充 第14段|先解释词义，再联系这次表达。|
|为什么迟迟说不出口|课本旁注 第14段|把原句解释为难以开口的原因。|
|第十五段：比考试还紧张|课本旁注 第15段|删去比较后，表达效果有什么不同？|
|歌声有什么含义|课本 阅读放大镜二；第16段旁注|联系前文，比较母亲前后的表现。|
|全文：用证据比较人物|课本 阅读放大镜三；第10段旁注后半问|自己写出特点，并用原句解释。|
|全文：爱需不需要说出来|课本 读后说|写出立场、理由、例子和回扣。|

儿子拒绝听文章及否定赞美是明示事实；是否爱母亲不可当作已确定的事实。教参相关说法作为可讨论解释，不能替代证据。结尾唱歌支持心情改善、感到爱与安慰，不支持从此完全结束哀伤。外貌/神态名称保留课本口径。开放题允许不同立场，无须披露家庭隐私。
