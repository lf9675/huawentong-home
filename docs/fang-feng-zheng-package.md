# 《放风筝》配套发布记录

中二高级华文，单元一，巩固课文。教材来源为用户于2026-10-19提供的14段课文截图、课本巩固练习及三张教参；三张30格漫画原样复用。

## 教学与资源

- 段落按1—14顺序推进；10组教学任务拆成14个短问题页。全文比较及开放回应放在读完全文之后。
- 第1段保留疑问，第3段才确定静音与漏接原因；第12段区分解压的明说信息与改善关系的合理推断。结尾不补写道歉情节。
- 第11段主要比喻，也接受有依据的拟人分析；课本将神态与汗珠归入外貌描写，课堂尊重教材口径。
- 第3段、妈妈出游原因、扩写、人物比较及自由与管教回应为主观输入。主观题不自动判内容正确；开放题要求立场、理由、例子及回扣。
- 三课时每课50分钟；两课时缩短汇报，并将部分短答改为口头共构，保留人物比较、开放题独立书写。
- 46页可编辑PPT、同步投影图、18页教师DOCX、原漫画、独立互动HTML及完整ZIP。超出单文件上限的下载由清单校验并自动组装，使用者无需拼接。
- 41项语境词库。个人词语本沿用共享存储，课文别名映射至s2u1l3。
