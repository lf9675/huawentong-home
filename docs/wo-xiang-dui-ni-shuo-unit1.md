# 《我想对你说》一课时教学配套

2026-10-20。用户明确要求制作并发布。位置：中二高级华文 → 单元一 → 生活空间，排在单元一第一项。按一课时50分钟设计。

## 来源与文本判断

依据本次上传的两张课文页、一张《阅读放大镜》题目页、两张教学参考，以及三张现有漫画。六条消息按教材顺序定位为六个教学段，保留发言者和时间；段号是教学定位，不冒称教材段号。三张漫画文件原样保留，24格按六段对应，每段四格。

教材题目完整覆盖：六个词语释义；三人的烦恼与辅导员建议；想对父母或辅导员说的话。教参2.2的口头概括与2.3的建议评价融入对话学习。原题没有分值和完整标准答案，所有答案与14分可选课堂评价均为教师参考。

关键边界：爸爸疲惫的原因未交代；“可以”是建议；美华是否提前告知及妈妈是否已经内疚未确定；“有些人”不证明匿名同学成瘾；“也许”不保证解决结果。漫画中的建议画面不当作真实结局。

## 教学与功能

先国明示范，再美华共构，最后匿名独立。六段依次阅读，不能提前看到后文；回看按钮只回看已经读过的有关段落。共8组任务，4道选择支架正确位置B、D、A、C，六个词语使用同一随机词库。国明、美华表格可口述并按需记录；匿名表格必填。最后开放回应必做3—4句，说明为什么，联系具体情境并回扣沟通效果。两项主要书面任务适配一课时。

多句证据可累加、粘贴、修改；首次错误5秒后可重试。首次答案、尝试及订正独立保存。匿名表格与开放回应由教师核对，不自动判分。支持姓名、班级、学号及JSON、CSV、文字导出。既有个人词语本按年级、单元和课文保存来源，跨课合并不覆盖学习者自己的释义与熟悉度；未知词可待补释义。本课32个语境词条，收藏由学生自主进行。

补充共同引擎的可填写表格与可选发言者标签，既有课文默认行为保留。开放题允许合理不同意见及明确的假设情境，不强迫公开私人经历。不增加新短文、延迟小测或打卡。
