## 老师只需完成这一次部署

1. 打开 [Google Apps Script](https://script.google.com/)，点击「新建项目」，命名为「选词填空2025-成绩接收」。请使用能编辑上方成绩表的 Google 账号。
2. 打开[已配好新表的完整代码](../bei/management/vocab-xuanci-2025-receiver.gs)，复制全部内容，粘贴进新项目的 `Code.gs`，替换新项目默认代码并保存。不要覆盖其他练习使用的项目。
3. 在函数列表中选择 `setupVocabProgress`，点击「运行」，按 Google 提示完成授权。这会核对并使用已建好的两个分页。
4. 右上角「部署 → 新建部署」，类型选「网页应用」，执行身份选「我」，访问权限选「任何人」，然后「部署」。如果学校账号不提供此选项，请先告知，不要更改学校安全设置。这个接收器不向访问者提供学生名单或成绩读取功能。
5. 复制部署完成后显示的「网页应用网址」（以 `/exec` 结尾），发回对话。不要发送密码或授权验证码。

菜单说明参照 [Google 官方网页应用部署指南](https://developers.google.com/apps-script/guides/web)。

## 接到网址后完成的验收

核对健康检查中的原表 ID、学习单 ID 和协议；使用明确标为测试的身份，验证真实写入、首次答案保留、订正、错题重做、重复提交及较旧版本处理；逐项读回原表，再按精确测试记录 ID 清理。通过后将 `submission-config.json` 中的 `enabled` 改为 `true`，发布并确认线上提交结果。
