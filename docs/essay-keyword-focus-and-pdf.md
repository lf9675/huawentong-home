# 作文题眼详写、结尾与完整 PDF

2026-10-19，学生服务 engine 2026-10-19.9。

## 教学判断

先判断题目核心词在本题中要求什么，再看原文实际详写了什么。生活化、篇幅长、情节曲折不自动等于扣题。以原文段号及逐字证据区分：重点及详写匹配、重点正确但未展开、主要详写另一个中心。

例如“勇敢尝试”需体现面对顾虑或不确定而作出尝试的选择和实际行动；“坚持”重在开始后仍继续。反复练习可以辅助，却不能代替从犹豫到尝试的关键转变。不能只因原文出现“勇敢”“战胜心魔”就判为充分扣题，也不要求每篇必须重复题目原词。先指出应压缩的偏重点段落，再指定需要展开的关键段落；修改建议落实到逐段示范。

结尾区分完全缺少抒情议论、已有但薄弱、感悟偏离题意、充分，以及体裁不适用。综合相关结尾段落检查回扣经历、内心感受、扣题的认识与解释；不强制固定句式。已有议论但偏向另一个道理，不能误称完全没议论，也不能夸为深刻切题。不足时给完整结尾示范，并修改相应段落。非记叙文不套用抒情结尾要求。

后端要求专项反馈字段、合法段号、逐字原文证据及对应的段落修改。偏重点与旧评分 gate 保持一致；仅完全缺失结尾时触发原版“缺少抒情议论”规则，薄弱或偏题由内容评价处理。原文按完整、有序的段号由程序绑定，模型不再重复抄写；语言引文须存在于对应原段。

## 完整 PDF

学生及教师共用“下载全部批改 PDF”，同时保留打印。包含题目、特别要求、总评、关键词详写、结尾、评分、全部原稿图片及红蓝圈注、全部原文（含保留段落）、逐段建议及英文解释、修改示范、全部语言批注及核对状态、整篇内容修改示范、教学建议与中文语音稿。

使用本地 PDF-LIB 1.17.1，按 A4 分页，页面在设备 Canvas 上以 180 dpi 绘制。无外部字体服务，也不上传数据；导出为图像型 PDF，文字不可直接选择。生成过程逐页释放画布占用；不截断长段落。图片加载失败时明确中止，避免悄悄下载缺页版本；旧记录从未保存原图的页面明确注明。远程原图导出前刷新签名链接。

生成后保留可再次点按的下载链接，以支持 Safari 异步生成后需要用户手势的情况。iPad 可打开 PDF 后用共享菜单“存储到文件”。下载不调用批改模型、不扣作文次数。旧批改结果不会因下载而自动重评；缺少专项检查的旧记录有提示。

## 验证

Node 回归覆盖段号绑定、拒绝虚构引文、关键词与评分一致、结尾缺失/薄弱/偏题的区别、非记叙文豁免、完整 PDF 内容和长行换行。实际生成 PDF 并检查原图数量、所有文本块、页边界与图片失败处理，再用 Poppler 渲染检查中文、颜色和分页。

本环境没有可用的 control-browser，未进行真实浏览器及 iPad 手势测试；Canvas 导出使用 Node Skia 兼容接口验证。AI 判断仍需教师核对，不能据此声称所有作文或所有错误均准确。
