# 作文题眼详写、结尾与完整 PDF

2026-10-19，学生服务 engine 2026-10-19.10。

## 教学判断

先判断题目核心词在本题中要求什么，再看原文实际详写了什么。生活化、篇幅长、情节曲折不自动等于扣题。以原文段号及逐字证据区分：重点及详写匹配、重点正确但未展开、主要详写另一个中心。

例如“勇敢尝试”需体现面对顾虑或不确定而作出尝试的选择和实际行动；“坚持”重在开始后仍继续。反复练习可以辅助，却不能代替从犹豫到尝试的关键转变。不能只因原文出现“勇敢”“战胜心魔”就判为充分扣题，也不要求每篇必须重复题目原词。先指出应压缩的偏重点段落，再指定需要展开的关键段落；修改建议落实到逐段示范。

结尾区分完全缺少抒情议论、已有但薄弱、感悟偏离题意、充分，以及体裁不适用。综合相关结尾段落检查回扣经历、内心感受、扣题的认识与解释；不强制固定句式。已有议论但偏向另一个道理，不能误称完全没议论，也不能夸为深刻切题。不足时给完整结尾示范，并修改相应段落。非记叙文不套用抒情结尾要求。

后端要求专项反馈字段、合法段号、逐字原文证据及对应的段落修改。偏重点与旧评分 gate 保持一致；仅完全缺失结尾时触发原版“缺少抒情议论”规则，薄弱或偏题由内容评价处理。原文按完整、有序的段号由程序绑定，模型不再重复抄写；语言引文须存在于对应原段。

## 完整 PDF

学生及教师共用“下载全部批改 PDF”，同时保留打印。包含题目、特别要求、总评、关键词详写、结尾、评分、全部原稿图片及红蓝圈注、全部原文（含保留段落）、逐段建议及英文解释、修改示范、全部语言批注及核对状态、整篇内容修改示范、教学建议与中文语音稿。

使用本地 PDF-LIB 1.17.1，按 A4 分页，页面在设备 Canvas 上以 180 dpi 绘制。无外部字体服务，也不上传数据；导出为图像型 PDF，文字不可直接选择。生成过程逐页释放画布占用；不截断长段落。图片加载失败时明确中止，避免悄悄下载缺页版本；旧记录从未保存原图的页面明确注明。远程原图导出前刷新签名链接。

生成后保留可再次点按的下载链接，以支持 Safari 异步生成后需要用户手势的情况。iPad 可打开 PDF 后用共享菜单“存储到文件”。下载不调用批改模型、不扣作文次数。旧批改结果不会因下载而自动重评；缺少专项检查的旧记录有提示。

## 验证

Node 回归覆盖段号绑定、拒绝虚构引文、关键词与评分一致、结尾缺失/薄弱/偏题的区别、非记叙文豁免、完整 PDF 内容和长行换行。实际生成 PDF 并检查原图数量、所有文本块、页边界与图片失败处理，再用 Poppler 渲染检查中文、颜色和分页。

本环境没有可用的 control-browser，未进行真实浏览器及 iPad 手势测试；Canvas 导出使用 Node Skia 兼容接口验证。AI 判断仍需教师核对，不能据此声称所有作文或所有错误均准确。

## 学生可读的对照反馈（2026-10-19.10）

总评保留“选材与扣题”“详略安排”“紧扣关键词详写”短标题，使用大号红色粗体。主要问题以 judgement 内逐字短语加粗，不重复展示总评 evidence 段落。

关键词和结尾用关系图及两列表格呈现：左边为段号与加粗的真实原句，右边为对应关键词、状态、简短问题及具体改法。既覆盖需要展开的关键时刻，也覆盖所有应压缩的准备／比赛段落；不能只列前者。屏幕小于 600px 时，每组原句和改法上下排列。较长的完整原段可展开，完整原文仍在报告中。

新反馈增加 emphasis、evidence_rows、flow、revision_notes 和 example_notes。后端检查引文是否来自指定段落，示范旁批是否唯一对应示范中不重叠的原句。遗漏纯展示行时，复用已验证的逐段反馈和真实原文补齐，不另行编造判断，不丢弃已经生成的完整批改。语义上仍要求老师核对：原句匹配不能证明 AI 的扣题判断必然正确。

示范保留完整正文；用红字标出具体扣题句，并紧接“扣‘关键词’：为什么”。不再只贴动作、心理、细节标签。准备受挫、反复练习或教师帮助不自动视为勇敢尝试；辅助内容要说明作用并实际压缩。原事的结果和人物行动顺序应保留。

旧报告直接使用已有关键词判断和原文生成表格，不自动重评；没有逐句扣题说明的旧示范明确提示。新生成的语义旁批需要按新指令重新批改。PDF 同步保留表格、关系图、加粗问题与红字旁批，并为跨页表格重复表头。

全文批改与呈现整理分为 `grade`、`presentation` 两个可续接步骤。前者先保存原评分和教学判断；后者只接收必要的教学字段，生成短评、表格、图示和示范旁批，不传回评分或语言批注。合并时只接受列明的呈现字段，不能覆盖评分、原文、扣题状态和语言批注。整理失败可单独重试，成功后重复请求不再调用模型；新任务在整理完成前不能进入最终扣次。旧客户端需刷新以获得新步骤。

验证增加：整理步骤的权限、失败保留、成功保存、重复请求及禁止提前完成；PDF 两栏长行和跨页表格内容完整性。未将测试草稿完成为学生提交，不扣正式学生额度。

全文批改中的单项语言引文若不属于对应原段，保存在 `unverified_red_issues` 并以独立待核对项目进入报告。它没有位置和圈注，不计为已确认错字，也不自动挪到另一段；保留其他有效批语，避免一条可疑引用使整份批改失败。对照表与示范的引文仍必须匹配，不能虚构。

对整句加粗或遗漏强调字段，程序从原评语的完整问题分句中选取重点，不编造新话；例如保留“未能充分支撑勇敢尝试”。对标为压缩的段落，若新示范仍超过原段 80% 的字数，会单独请求精简该段并重新核对引文，失败则保留已完成的全文批改供继续整理。

对照表同时覆盖原总评证据中明确引用的段号及段号范围，例如“第5、6段”“第3段到第6段”，即使旧记录的压缩段落列表漏填，也从真实原段补入对应原句并保留已有总评和改法。旧报告因此能显示此前漏列的比赛段。
