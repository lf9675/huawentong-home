# V1.16 生成器设计与成绩后台核查

## 作文教学的独立流程

本轮检查xie与xiezuo的作文资料；旧目录兼容页追到当前维护页。主要设计依据：

| 仓库资料 | 可复用的教学流程 |
| --- | --- |
| xiezuo内六篇作文审题活动 | 题目限定、中心与关键词；比较选材；详略；关键场景；个人写作路线 |
| xiezuo/s1-jineng与s2-jineng | 开头扣题并进入事件；结尾回、感、悟；未来行动是提升项，不机械强制 |
| xiezuo/fanwen内范文 | 段落功能与句子批注；选材、因果、描写、照应；比较与迁移，避免背全文 |
| xie/narraessay.html | 情境记叙文的审题与结构训练 |
| xie/shared/zuowenzhidao.html | 记叙文与材料议论文分流；关键词、审题、局部写作；PEEL为论点、阐述、例证、回扣 |

作文工具不要求填写词语表。教师选择文体、课堂阶段、训练重点，并填写完整作文题目；写前可不提供范文，写中与写后必须提供相应片段或匿名作品。未提供材料议论文的材料时不能杜撰。

写前：题意与限制→中心→选材比较→结构与详略→个人构思。写中：一个具体目标→原句与升格对照→局部练笔→独立迁移。写后：匿名作品证据→问题与理由→修改对照→迁移；不按关键词数量或字数代替作文质量。

记叙文训练扣题、情节因果、详略、具体描写与真实感受。材料议论文训练读懂材料、界定观点、解释理由、使用例证并回扣题意。教师未提供“七问”或A–D分类定义时不自行创造。选择题只辅助判断，必须保留至少一次独立写作任务；开放题不冒充自动批改。

## 输出截断处理

原代码每批四题，生成、审查、修正遇到finish_reason=length或不完整JSON即停止。现有hwt-ai-proxy仓库只是原样转发请求，没有发现额外截断参数；这不等于已取得用户那次真实请求日志。

本轮改为小批生成与审查；可恢复错误自动拆成单题，单题仍失败则有界重试。教学元数据独立生成，不要求一并输出整份题库。已完成题目在当前浏览器保存为草稿，重试可续接；密钥不存入草稿。已完成的题稿仍须通过程序检查与AI逐题审查才可下载。

## 成绩现状与接入

本轮直接读取线上数据库计数：Clever.华文通组织的zuowenpigai项目（rodtizxezbtlhnuljzsc，新加坡区），原为INACTIVE，本轮恢复为ACTIVE_HEALTHY。assignments 25、submissions 69、essay_records 69、error_tags 1413；这是旧作文批改记录，未读取学生姓名、作文全文或密码内容。原有8表数据未迁移、未删除。list_tables的rows=0是目录统计，不能代替实际count(*)。

cilang-platform使用SQLite；zuowenpigai仓库使用Streamlit私有配置SUPABASE_DB_URL与psycopg2连接数据库。当前连接仅显示一个组织、一个项目，不能排除截图另一组织内还有其他记录。原生成器成绩仅在学生页面导出和教师本地导入，没有Supabase回流。

本轮新增5个独立hwt_*表：hwt_settings、hwt_sessions、hwt_rate_limits、hwt_lessons、hwt_attempts。已实际确认全部启用RLS，anon不能直接读取或写入。密码校验转到服务端，沿用原密码摘要；随机会话8小时有效，退出撤销。数据库管理密钥只在Supabase函数环境内使用，学生HTML只含该学习单的提交凭据。

hwt-classroom函数已部署；网关verify_jwt=false由函数内自定义认证接管，不表示匿名可以查询成绩。教师操作逐项验证会话；学生提交凭据只允许写入指定学习单，不能读取全班记录。全局及来源登录请求有界限流，学生提交按学习单限流。新的学习单下载时登记不可变内容版本；学生完成后自动提交逐题记录，服务端重算客观题分数；重试去重，不能覆盖同一次首次作答。网络失败明确提示并提供重试、作答备份；当前标签页保留未成功上传的提交。

后台列表按学习单、版本和班级读取真实记录；同班同学号采用首次提交分析，重做另计。组别选填；班级、学号与姓名必填但尚未验证学生身份。开放题保留自评，teacherScore始终待覆核，本轮尚未制作教师覆核录分界面。没有把自评作为自动成绩。当前交互在首次作答后锁题，不采集不存在的订正成绩。

“一键错误分析”使用真实逐题选项统计，教师可先查看名册和独立客观题分数。发送AI的只有题目与汇总，不含学生姓名、学号或原始答卷；缺少全班名册时不能估计缺交人数。AI报告区分小样本、共构与独立作答、未覆核开放题。“AI根据错题改进学习单”载入所选旧版，按统计生成候选题稿，再经过原程序检查及AI审题；教师下载时产生新版本，不改旧题单或历史成绩。替换当前未发布草稿前有页面确认。

## 仍存在的旧库权限问题

旧8表RLS未启用，anon/authenticated仍有广泛读写权限。自动审批拒绝了本轮启用旧表RLS的迁移，理由为可能影响旧服务，并引用早期不改权限的限制；未通过其他通道重试。supabase/sql/protect-legacy-essay-tables.sql是待批准方案，不是已执行迁移。旧服务用服务端Postgres连接，但实际部署连接角色及其他调用者未获验证，不能保证改权限后旧应用不受影响。需确认允许修复这8表权限后执行并验旧作文服务。
