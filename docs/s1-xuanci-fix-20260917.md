# 中一选词填空修复记录（2026-09-17）

适用页面：练习一（2024）、练习二（2023）、练习三（2022），各20题、25个备选词语。

## 故障与修复

原共用程序将 `CSS.escape(num)` 的结果拼进 `getElementById`。数字题号会被转义，无法匹配页面上的真实题目ID，随后调用 querySelector 时中断，因而已填正确答案仍不能核对。现改用原题号组成的真实ID，并对60题作完整判分测试。

保持蓝白版式、楷体题目及原题号与答案；修复修改答案后仍显示旧判分的问题。初答得分保留；每次答错都会进入错题本，包括初答正确、后续答错的题。反复点击同一结果不会重复累计。错题重做前隐藏答案，保留首次和最近错答，订正及重做不覆盖初答得分。空白/纯标点不判错，中文输入法组词期间不触发核对。

关键词继续红色粗体；核对后整句、关键词及输入框统一蓝色或红色。难词与关键词重叠时仍可查看释义。浮动释义提供中英解释，支持鼠标悬停、触屏点按和键盘，避免被侧栏或屏幕边缘截断。增加返回中一词语练习入口。
