# 作文教学反馈恢复（2026-10-19）

## 使用入口

- 学生：`/xie/zuowen-pigai/`
- 教师发码：`/xie/zuowen-pigai/teacher.html`，原有发码和额度管理保留。
- 作文审核与讲评：`/xie/zuowen-pigai/teaching.html`，使用现有教师密码／会话。

教师先打开作文，回看原图，逐条确认、修改或排除问题；需要时启用“在原图重新框选”调整位置；用“补一条漏批／好句”补充 AI 遗漏的项目。回到列表选择相同题目、相同文体的 1–10 篇作文，生成讲评材料，生成后再独立复核一次无意新增的语病与答案对应。只有教师确认的问题进入错误统计和生成素材。学生练习版不显示答案；教师版含答案、修改示范与教学建议；PPT 为可编辑文字与教师备注。

## 学生批改流程

1. 图片或 PDF 转为页面 JPEG。页数、大小校验沿用原有上传限制。
2. Gemini 逐行抄录，再回看原图复核，保留两次抄录差异和不确定标记。
3. 学生／教师对照原图确认文字。真实错别字应保留；划掉字、插入符号和识别误读应更正。未经确认不能开始批改。
4. 按自然段批改与分块语言复核：先选材、扣题和详略，再逐段问题、简单解释与修改示范。跨页延续的段落合并；不强迫每一段都改写。
5. 每个语言问题／佳句回看原图，排除识别误差、废弃文字、可选润色。疑点不作为确定错字扣分。
6. 错字附近的局部图再次放大定位，坐标由程序换算回整页；局部核对不一致则留待教师确认。确认存在的错字用红圈、病句用红波浪线、佳句用蓝波浪线。鼠标悬停和触屏点按显示解释。原图位置仍是模型估计，教师可以手动调整。
7. 完成后才扣次数，已完成的各步可恢复。PDF 通过完整打印报告保存，逐段示范会展开；语音使用设备的中文／英语朗读能力。

## 服务和部署

- 新前端调用 `hwt-essay-v2`；源文件在 `supabase/functions/hwt-essay/`。保留旧 `hwt-essay`，允许部署时已有旧页面继续完成。
- 教师接口 `hwt-essay-teaching` 复用 `hwt-classroom` 的教师会话；学生访问码不能访问教师资料。
- 按 `supabase/sql/hwt-essay-teaching.sql` 部署私有原图 bucket、审核记录、讲评材料与事务函数。
- Gemini 密钥只在 Edge Functions secrets。原图 bucket 私有，按作文归属／教师会话发放短期签名链接。
- 审核使用版本比较防止覆盖他人修改；讲评使用输入摘要和租约缓存，重复请求不重复生成。
- 新记录保存原图；没有原图的历史记录只能查看文字意见，不能凭空恢复照片圈注。
- 前端 PowerPoint 库为本地托管 PptxGenJS 4.0.1，附 MIT 许可证。
