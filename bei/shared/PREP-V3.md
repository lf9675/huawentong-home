# 华文通备课工具 v3

三个入口共用 `bei/shared/prep-v3.js`，生成的学生 HTML 内嵌题库与引擎，可离线使用。教师侧 PPTX 导出使用 PptxGenJS 4.0.1；首次导出须联网加载该库。

参考上传的 cilang-platform：claude_prompt.md 的词义／用法／辨析路径，claude_prompt_reading.md 的整体结构／意义段／主旨路径，以及 quiz_template.html 的选项打乱、反馈机制。未搬用 Streamlit、数据库或已有成绩代码。

流程：填写材料 → 可编辑大纲 → 确认生成 → 题稿结构检查与人工语义审核 → 下载。直接执行跳过大纲确认。API 密钥只留在输入框和本次请求，不写入下载文件或存储。

分数是本设备客观题的首次作答分。开放题自评单列，须教师覆核。导出作答 JSON 可供汇总；尚未配置 Google 表单或跨设备班级榜，本版不声称具备自动汇总。
