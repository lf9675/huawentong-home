2. 在 Google 新建接收程序
  1. 用已获编辑权限的 lyqlym2015@gmail.com 登录 Google，打开 Apps Script，点击新建项目 / New project。
  2. 项目命名为阅读成绩接收－善待生命。打开默认的 Code.gs，全选其中的示例代码并粘贴刚才复制的内容，按 Ctrl+S 保存。不要改动旧项目。
  3. 在编辑器顶部的函数下拉框选择 setupReading，点击运行 / Run，用上述账号按 Google 提示授权。程序会创建成绩表头；日志显示“阅读成绩表已准备好”后继续。
  4. 右上角部署 / Deploy → 新建部署 / New deployment；类型选择网页应用 / Web app。
  5. 执行身份 / Execute as 选我 / Me；谁可以访问 / Who has access 选任何人 / Anyone。点击部署 / Deploy，按 Google 提示为你刚创建的程序授权。
  6. 复制部署结果中的网页应用网址（以 /exec 结尾），粘贴回 ChatGPT 对话。我会配置网页并完成真实提交测试。
