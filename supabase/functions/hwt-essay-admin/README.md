# 作文访问码管理

页面：`/xie/zuowen-pigai/teacher.html`，学生批改页与 `/bei/` 教师工作台均有入口。

教师用现有华文通教师密码登录。登录与退出调用 `hwt-classroom`，复用其 8 小时会话；本接口每次请求与数据库事务内均检查 `hwt_sessions` 的有效期。不能使用学生访问码或旧 Streamlit 的管理员密码登录。无需增加 OCR、AI 或教师密码密钥。

## 部署

1. 应用 `supabase/sql/hwt-essay-admin.sql`，为旧访问码表增加管理版本号，并建立仅服务端可访问的操作记录表。
2. 部署 `hwt-essay-admin`，入口 `index.ts`，导入映射 `deno.json`。关闭网关 JWT 检查，因为函数已实现自定义教师会话认证；不能移除函数内的会话检查。只使用 Supabase 自动提供的服务端环境变量。
3. 发布静态页面。教师密码仍由现有华文通设置管理，本迁移不修改任何密码。

## 行为

- 每批 1–100 个访问码；分别设置新作文额度、总次数、考试段、到期日、备注。
- 到期日期含当日，按新加坡时间。新码必须填写有效日期；旧码可保留不限期设置。
- 使用原 `access_codes` 和 `code_usage_log`；编辑总额度保留已使用计数，且不能降至已用次数以下。新作文额度为 0 时沿用旧码的共用总次数规则。
- 更换访问码原位更改其哈希，保留编号、状态、所有计数与历史；旧码立即失效。
- 页面使用浏览器密码学随机数生成访问码，服务端只保存 SHA-256。完整码仅在当前页面显示，并可下载 CSV；旧码无法反查。
- 操作编号与载荷摘要提供事务内幂等保证。网络结果不明确时保留待处理操作，点击“重试同一次操作”；刷新前有提醒。操作记录只含管理元数据，不保存明文码或会话令牌。
- 行锁与批改完成操作一致；管理版本号拒绝新版多页面的过期修改。原 Streamlit 管理端不使用此版本号，建议教师统一从新版管理。
- CSV 处理引号、换行和公式前缀；浏览器输出转义备注与使用者称呼。

## 验证

`node --test tests/essay-admin.test.mjs tests/essay.test.mjs`

`tests/essay-admin-database.sql` 是真实数据库集成检查，包含权限、事务回滚、重复请求、过期版本、配额、停用、换码及学生任务兼容性。测试使用事务内会话和访问码，最后全部回滚；不会保留测试登录或消费学生额度。测试虽回滚，PostgreSQL 序列编号仍可能出现间隔。

新管理服务与 AI 供应商独立。发码成功不代表 OCR 账户余额、识别质量或批改准确率已经验证。
