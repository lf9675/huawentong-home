三、iPad 使用前检查
1. 联网时在课程首页点“下载学生单文件版”，保存到“文件”。
2. 用能执行 JavaScript 的浏览器或本地 HTML 阅读器打开下载文件。
   注意：iPad“文件”App 的快速查看/预览可能不执行 JavaScript，不能保证练习可运行；它不等于 Safari。
   若只有静态预览、提示预览器不支持，或下一段/练习按钮不工作，请改用允许本地 HTML 脚本的阅读器，或暂用原在线课程。
   本次未验证特定第三方阅读器，不承诺 Safari 能直接打开“文件”中的本地 HTML。
3. 先点“下一段”、红字词语和一道练习，再开飞行模式，核对漫画与练习仍可使用。
4. 正式课堂前，在学校实际 iPad 和打开方式上完成一次上述检查。
下载文件与当前 Safari 已打开的在线页是两种使用方式；仅打开过在线页不保证断网后可用。

四、学习记录
Record 填姓名、班级、学号；Export CSV 导出逐题明细，Backup JSON 备份全部作答和草稿。
首次答案和订正尝试分别保留；开放题需自评/教师覆核，不自动判分。
离线版新增 Import JSON：可恢复本课同版本备份，导入前确认替换，错误文件不覆盖当前记录。
导出后如未自动下载，使用 Share（设备支持时）保存到“文件”，或点 Open / 复制导出内容另存。
本次 Chromium 已验证下载；iPad 分享与保存流程尚未真机实测。
记录尽量保存在当前浏览器本地；文件预览器、隐私模式或存储限制可能阻止保存。
存储不可用时页面会显示提示，仍可当次作答，请在关闭页面前导出 JSON。
更换设备、移动/重命名文件、清浏览器数据或更换阅读器前务必备份。
在线页和本地文件不自动互通记录；可从在线页导出本课 JSON，再在离线版导入。
没有自动上传教师后台或 Google Sheet；不承诺跨域、跨设备或跨文件自动同步。
