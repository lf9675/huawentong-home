TEACHER GUIDE · ARGUMENTATIVE READING

《合作》教师端：篇章理解路径＋考试迁移

这版不把Q50–Q53当作起点，而是先训练“句子逻辑 → 段落结构 → 全文结构”，最后才迁移到考试作答。

课堂定位：学生端约80%用于理解篇章，最后约20%用于Q50–Q53。先让学生通过操作“看见”逻辑，再命名 Point / Evidence / Explanation / Conclusion。

一、设计依据

读句子
关注关联词、连接词，以及句子之间的逻辑关系。
读段落
抓中心句、过渡句，理解 Point、Evidence、Explanation、Link。
读全文
把段意串起来，读出总分、并列、递进、对照等结构。
做题
考试答案从篇章结构中自然推出：Direct Info优先，需要时再Inference。

二、课堂流程（约25分钟）

第1步｜我做：第1段“总起 → 三个例子 → 中心论点”

总起句：人不是孤立存在→例子：学生／运动员／军人→中心论点：人人都离不开合作
  • 教师先问：第一句为什么不是例子？三个“作为……”为什么是例子？“总之”后面为什么是全文中心论点？
  • 再问：“总之”前后发生了什么变化？
  • 最后才命名：具体→概括；三个结构相近句子共同说明一个观点，因此构成排比。
  • Q50迁移：作用必须写“从不同身份说明人人需要合作，突出合作的普遍性和重要性”。

第2步｜我们做：第2段“定义 → 说明 → 强调”

句子工作
合作，顾名思义，就是互相配合，共同把事情做好。定义：合作是什么
世界上有许多事情……一个人能够与别人合作，也就获得了成功之匙。说明：合作为什么重要
小合作有小成就……强调：进一步强化合作与成就的关系
段意：解释什么是合作，并说明合作对取得成就很重要。

第3步｜我们做：第3段“找分论点 → 看怎样论证 → 连回中心论点”

Point：统一目标→Evidence：交响乐团→Effect：完美和谐、打动听众→证明统一目标的重要
  • 追问：“如果删掉交响乐团，观点还在吗？”——在，但说服力变弱。
  • 让学生发现：论据不是新观点，而是服务于前面的Point。
  • 压缩时删掉音乐厅、电视、指挥棒、唇边、指缝等细节，保留“统一目标＋交响乐团＋效果”。

第4步｜你做：第4段“找分论点 → 正反因果链 → 连回中心论点”

只顾个人→忽略整体→即使能力强→仍难取胜
团队目标→必要牺牲→取得好成绩
  • 结构词：不仅……还……；最重要的是……；如果……那么……；只有……才……
  • 学生应压缩成：成功合作除了统一目标，还要做好本职、顾全集体，并在必要时牺牲个人利益。
  • 这是Q51、Q53最重要的理解基础。

第5步｜你做：第5段＋全文

竞争但同时更需要合作→提升合作能力只有这样走得更长更远
全文板书：为什么需要合作 → 什么是合作／为什么重要 → 怎样有效合作 → 现代人应该怎么做。

三、学生可能卡住的地方

卡点1：把例子当答案
Q51写交响乐团、足球。
追问：题目问“条件”还是“例子”？
卡点2：只会找词，不会看关系
看到“如果”“只有”却不会解释。
追问：条件是什么？结果是什么？
卡点3：段意写成细节堆积
把指挥棒、乐曲、球员全写进去。
追问：删掉这些细节，作者最想说什么？
卡点4：主旨过度简化
只写“合作很重要”。
追问：作者花两段写“怎样合作”，为什么你的主旨没有？

四、Q50–Q53参考答案与评分

Q50（3分）

Skill 第一段采用了排比。
Direct Info “作为学生……共同完成学业；作为运动员……共同打好比赛；作为军人……共同保卫祖国。”
Inference 通过不同身份说明人们都离不开合作，强调合作的普遍性和重要性，使说理更严密、更透彻，并增强气势。
1分排比
1分相关句子
1分具体作用，必须联系“人人需要合作”

Q51（4分）

①有统一目标；②做好本职工作；③心中想着集体／顾全集体；④有自我牺牲精神，必要时愿意牺牲个人利益。
不给对应条件分：只写交响乐团、足球比赛。

Q52（3分）

作者以交响乐团的演奏为例。乐师们有一致目标，在指挥下互相配合，使演奏达到完美与和谐，也让乐曲打动听众，使人感受到音乐之美。
1分交响乐团
1分演奏完美和谐
1分打动听众／感受音乐之美

Q53（4分）

示例：我同意。合作是为了完成共同目标，如果每个人只顾自己的方便，团队可能无法完成任务。例如，一次小组汇报时，一名组员生病，我原本计划周末和朋友外出，但为了让小组准时交作业，我取消活动，帮他整理资料，并和组员重新分工。最后我们顺利完成汇报。我牺牲了自己的休闲时间，却帮助团队完成共同目标。
1分明确立场
1分解释为什么／阐释观点
2分贴题生活例子：明确“牺牲什么个人利益＋团队得到什么”
不同意也可：只要理由合理，且生活例子真正支持立场。

五、教师最后板书

合作不可缺少→合作＝互相配合→统一目标＋本职／集体／牺牲→提升合作能力
一句话收束：学生不是“回答关于文章的问题”，而是在网页上亲手重建作者的思考过程。
