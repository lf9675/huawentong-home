# 中一全课文词语学习单

范围：教师上传的《中一词语表.docx》，6单元、24课、305个课内词语条目（303个不同词形；“狼狈”“泡沫”跨课重复，分别保留）。本词表独立于考前听写删减清单，不删除“艘”“屁股”；“娘惹”为完整词语。

## 已确认的教学设计

用于新课文初学：教师先简讲，学生用简短字义线索和语境选择理解词义，难词加入关系示意图。每词一道语境题及一道新的填空情境，不要求打字，不计时、不排名。每课5个课堂重点词先呈现，其余词义题可展开；只有5词的课不显示空补练栏目。

填空必须覆盖本课全部词语，全部放在同一词库，每题下拉选项均为全课词语，不能拆小词库。每词使用一次。自然近义替换“一诺千金／言出必行”在本课两题都接受；重复使用仍会提示。词库随机排列，词义题正确项位置按课均衡打乱并保存。

## 内容与来源

- `content/lessons.json`：按用户词表原顺序保留年级、单元、课名、词语；总覆盖量可复核。
- `content/unit1.tsv` 至 `unit6.tsv`：词语、线索、情境、正确项、两干扰项、迁移填空、解析。每行8字段，以 `|` 分隔；跨课同词按课序独立处理。
- `content/visuals.tsv`：66个难词的三节点关系图；`visuals.js` 补充11个词的方向、位置、时间、字形对照示意，共77个词语条目有图示。
- `build.py`：生成 `concise-data.json`、`teacher.html`。运行 `python du/ciyu/context-lab/s1/build.py`。
- 单元一至三词义参考用户提供上册课文；全部学生情境均为教学新设，不冒充课文引文。未取得本地下册全文，不作下册情节或引文断言。
- 词义校核参考：国家文物局 Roots（新谣）、土生文化馆（娘惹）、中国政府网（华侨）。链接附在教师页对应词下。
- 字义拆解与记忆图示不宣称为古文字字源；无需可靠来源的造字故事不编写。强调比喻与本义、语境多义和形近字：机械、滋味、牺牲、凸／凹、账／帐等。

## 实现与维护

学生入口 `index.html?unit=1#s1u1l1`；可用单元1—6筛选；教师入口 `teacher.html`。

独立的中一数据和本地存储键，复用上级样式、图标；不改动中二数据或学生进度。进度只保存在当前设备，不能跨设备同步；设备拒绝存储时显示提示。

## 八关审查（本轮）

1. 课堂目标：词义理解与新语境运用，不增加考前默写任务。
2. 内容依据：逐课核对原词表；不编造原文引句。
3. 语言：短中文线索、短情境，简单词不强加多步流程。
4. 认知负担：5词先展示，其他可按需打开；完整词库保留用户要求的辨别难度。
5. 评价：干扰项区分字面误读、相近意思及语境；近义填空允许合理替换。
6. 互动：点选、错误提示、重试、朗读、本机保存，无倒计时排名。
7. 数据：逐词构建校验、字段断言、无遗漏、无课内重复。
8. 实施：独立入口，首页六单元链接，浏览器和线上发布后校验。

本轮不需要教师裁决的未完成项；真实iPad Safari仍需课堂实际使用验证，不把桌面模拟称作实机测试。
