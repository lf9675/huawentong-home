# 中二课文初学：词语探究

本工具服务老师简要讲解之后的学生自主探究；与 Quizlet、workbook 配合，不是考前选词填空或汉字测验。覆盖中二单元一至四，16课、204词。沿用用户原练习“由字词线索理解语境义”的理念，用关系图减轻文字负担；不复制有疑问的字源断言。

## 学习目标与流程

1. 学生能观察图中动作、前后变化或对比，说出词义关键区别。
2. 学生能结合本课原句，区分本义／引申义、客观事实／人物猜测，并指出支持理解的词句。
3. 学生能辨认目标字的结构、易混部件；可解释的形义联系用作记忆线索，不强行拆义。

教师先选本课约5个词，简要介绍语境；学生依次“观察辨义→回文选依据→观察字形”。不要求全课所有词一口气完成。具体名物、动作、情绪、逻辑词采用不同问题；数量词使用准确数量关系，趋势示意注明非课文数据。

学生可选多格图示作为线索。每词一道3选1探究题，首次错误给观察方向，5秒后可再选；两次错误后可看解释再试。选择顺序按课内均衡位置随机分配并保存在本机。

答对后仍需回文选依据、写一句理由或向同桌口头解释。电脑不判依据、开放解释与口头说明对错，需教师抽查；“已说依据”只表示完成相应过程。教师追问：“这句话怎样支持你的解释？还有没有另一种意思？哪个词限制了意思？”

168个词提供针对性部件比较；其余保留逐字放大，不编造字源。练写是可选观察活动，也可直接写在 workbook，不自动评分。没有考试分数、倒计时或排名。

## 原文与内容边界

来源：用户提供《2022 2A-课文word.docx》《2021中二下册高级华文电子课文.docx》。已提取正文及表格；每个引用均与文档逐字核对（仅忽略空白）。用户课名保留为入口名称，引用处另显示电子课文的原题名。source-data.json保存相关段落用于复核；未复制整本电子课文。

- “捧跤”据原文改“摔跤”；最后一课重复词表去重。
- “匿名”保留表格中的署名位置作证据。
- “吨”在所给本课可提取文本中未出现，标为词表延伸，不编造原句。
- “涂上颜色”是用户词表短语；原文为“涂了蜡似的小红嘴”，明确标注对应关系。
- 窒息、疙瘩、光辉、涩涩、涌动、捅等按课文引申义设计。
- 《猫》的畏罪潜逃是错误猜测，惩罚不证明对象有罪；凝望也不证明吃鸟。
- 《母与女》的臃肿、庸俗属于叙述视角，不把外貌和人格等同。
- 旧生活插图仅为折叠的辅助例子，不标为课文事实。主图是可维护、带文字替代的SVG关系示意。

## 内容与代码

- unit1.tsv至unit4.tsv：204道逐词编写的问题、选项、图示节点、解析。
- glyphs.tsv：可核对的部件比较；部件不是声称已证明的字源。
- build.py：合并上述内容及课文摘录生成data.json；重建命令 `python du/ciyu/context-lab/build.py`。
- index.html / app.js / style.css / icons.js：学生端。
- teacher.html：教师流程、答案与语境索引，与学生页分开。

本机记录新键hwt-context-lab-v1，与旧版成绩隔离。保存失败有提示，允许导出文本和JSON；画布另存本机，不包含在文字/JSON备份内。未接服务器、班级成绩表或Google Sheets，不要求学生填姓名。

## 验收原则

必须检查204词覆盖、引用来源、唯一选项、图示与文字一致、字形比较位置、各课入口、重试与存储、移动屏幕溢出、SVG显示。不能把完成点击、看过解析或自报口头说明当成独立掌握。

网络不可用时，由教师使用teacher.html的打印版或已有workbook继续；在线页不声称离线可用。教学设计依据用户澄清：本工具优先初学探究，不添加考前检测流程。
