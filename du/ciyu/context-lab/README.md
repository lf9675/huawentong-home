# 中二课文词语学习单

教师在 2026-10-01 确认样本后，按「简明字义／字形线索 → 情境选择 → 少量选词填空」扩展。适用于新课文初学，已有 Quizlet 与 workbook；不是考前听写工具。

## 课堂结构

- 4 单元、16 课、204 个不重复词语，严格按课文归属。
- 每课先呈现 5 个重点词及 5 道新情境填空。其余词语折叠为可选补练，全部 204 词各有一道情境题。
- 49 个较难词有关系或动作示意图，另有「疲惫」字形卡。简单词不强行配图或讲故事。
- 中文题目、短提示、点选作答，无强制作文式解释、查找证据、打字或手写流程。语音使用设备普通话声音，不保证每台设备音色一致。
- 教学场景明确标为「学习情境」；可能改编课文，也可能为教师新设，不伪称逐字原句。原句在教师参考中单独保存。
- 教师可直接发每课链接：`index.html#s2u1l1`。旧格式 `#s2u1l1/0/observe` 仍定位到对应词。
- 知识正确性：「疲／惫」身体与精神只是记忆线索，不是词义的绝对分界；形声、成语来源有来源链接，其他拆词和形象联想不冒充古文字字源。
- 不计时、不排名；本机保存进度，初次选对与重试后完成分别保存，不声称考试成绩或自动上传班级成绩。

## 词表核对

- 用户的「捧跤」据课文改为「摔跤」。末课重复清单去重。
- 「吨」为词表延伸，未编造课文引文；「涂上颜色」为用户词表短语，相关课文说法是「涂了蜡似的小红嘴」。
- 《猫》「畏罪潜逃」是家人的错误猜测；词义练习不得把误解当事实。
- 《母与女》「庸俗」是叙述者最初的主观评价；体形不证明品格。
- 《恐怖事件》「诡异、恐怖」描述感受，不证明超自然事件。

## 编辑与构建

正式内容：`concise/contexts.tsv`（字义线索、短情境）、`concise/questions.tsv`（一道题、唯一正确项、两个干扰项）、`concise/cloze.tsv`（每课五题及提示）。

重建：`python du/ciyu/context-lab/concise/build.py`，生成 `concise-data.json` 和 `teacher.html`。

`data.json`、`source-data.json`、`unit*.tsv`、`glyphs.tsv` 保留为原句和旧内容的复核资料。旧多步骤 UI 已替换；`build.py` 是历史构建器，不用于新版发布。新版只读取 `concise-data.json`。

界面：`index.html`、`app.js`、`style.css`、`icons.js`、`concise-visuals.js`。答案位置按每课、课堂重点组均衡打乱，刷新不改变已保存的顺序。

教师参考提供字义、学习场景、答案、解释、干扰项、课文原句与部分词源链接，可以打印。学生无需提交个人资料。

## 审查和验收

课程：初学辨义，不添加考试式长答；语言：情境压短、逐词检查词义；认知负荷：五个课堂重点、其他按需；评价：204道唯一答案，80道新情境填空；互动：点选、重试、刷新保存；来源：原句与教学创设分开；实现：内容与模板分开。

浏览器验收记录见 `concise/verification.md`。浏览器模拟 iPad 尺寸不等同真实 iPad Safari 实机验收。
