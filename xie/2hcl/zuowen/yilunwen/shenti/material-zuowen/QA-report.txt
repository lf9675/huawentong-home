材料作文审题练习 V4.2 验收
==========================

本次修改
1. 删除学生流程中的“新题练习 / 换一题再做 / 迁移”。
2. 在“分论点”之后加入“完整文章结构 / Complete essay outline”。
3. 文章结构依据教师上传《作文7_提纲与答案》设计：引论 →（建议题可简写Why/危害）→ 过渡句 → 本论分论点 → 结论。
4. 学生先选出3个分论点，再补写每段 Explain 计划、Example 计划、Link / So What，并填写结论。
5. 学生完成独立 PEEL 并对照参考后，才出现“查看完整范文”按钮。
6. 完整范文提供“标注版 / 连贯阅读”两种阅读方式。
7. 社区凝聚力范文按教师上传《Q1 民众俱乐部活动如何促进社区凝聚力-范文》转为网页，并注明原范文有4个分论点，一般程度学生写好3点也可以。
8. 教师上传《Q2组屋区的环保设计提升居民的生活品质-范文》题目与当前“绿色校园”题不同，因此没有误标成当前题答案；只参考其范文组织方式。
9. 三题均保留中英术语支架。
10. v4-engine.js 与三个 data 文件均已通过 JavaScript 语法检查。

教学流程
审题 → 关键词 → 材料线索 → 中心论点 → 分论点 → 完整文章结构 → 老师示范 PEEL → 一起做 → 自己做 → 完整范文
