# 02　接 Google 表格：审题卡自动汇总

预计 15 分钟，一次做完，六篇作文全部通用，以后加新作文不用再做一次。

---

## 做完会得到什么

学生按完最后一关，画面下方会跳出「✓ 已交给老师」，
你的 Google 表格里就多出他写的中心、选材、核心片段。

**收作文之前先扫一遍表格，跑题的人当场就看得出来。**

先讲清楚一件事：这六套网页**不产生 0–100 的分数**，
只产生「一次答对／修正后答对／看了答案」三个过程数字。
所以做不出真正的排行榜，我不会假装做得出来。
表格给你的是**审题卡内容**，这比一个假分数有用。

---

## 步骤一：开一个新的 Google 表格

1. 浏览器开 `https://sheets.new`（会直接开一个空白表格）
2. 左上角「未命名的试算表」点一下，改名为：**作文审题成绩**

**预期看到**：一张空白表格，标题变成「作文审题成绩」。

---

## 步骤二：贴进后台程序

1. 上方选单：**扩充功能** → **Apps Script**

   **预期看到**：跳出新分页，标题「未命名的专案」，中间有个编辑区，里面写着
   ```
   function myFunction() {
   }
   ```

2. 在编辑区里点一下，按 **Ctrl+A** 全选，再按 **Delete** 全部删掉
3. 用记事本打开 `teacher-only/Code.gs`，**Ctrl+A 全选、Ctrl+C 复制**
4. 回到 Apps Script 编辑区，**Ctrl+V 贴上**

**预期看到**：编辑区里是一大段中文注解开头的程序，第一行是
`/********** 华文通 · 作文审题区 成绩后台 …`

---

## 步骤三：改你自己的密码

1. 往下滚约第 8 行，找到这一行：
   ```
   const TEACHER_PIN = "1234";
   ```
2. 把 `1234` 改成你自己的密码，例如 `nhhs2026`
   （引号要留着，只改中间的字）

⚠️ 这个密码和 class-reading 的 TEACHER_PIN、南华熊的教师密码**是三套完全不同的东西**，不要混用、也不要设成一样。

3. 按 **Ctrl+S** 存档

**预期看到**：上方「未命名的专案」变成可以编辑的状态；随便打个名字如「作文审题后台」，按确定。

---

## 步骤四：先在这里测一次

不要急着部署，先确认程序跑得动。

1. 编辑区上方有一排：**执行**、**除错**，旁边有个下拉选单
2. 下拉选单选 **自测**
3. 点 **执行**

**第一次会跳出授权画面**，照这样点：
- 点 **审查权限**
- 选你的 Google 帐号
- 出现「Google 尚未验证这个应用程式」→ 点左下角 **进阶** → 点 **前往「作文审题后台」(不安全)**
  （这是你自己写的程序，安全）
- 点 **允许**

**预期看到**：下方「执行记录」出现四行，类似
```
交卷：{"ok":true,"msg":"已收到"}
总览行数：1
内容行数：2
清空：{"ok":true,"msg":"已删除 201 班 3 行记录"}
```

回到表格分页看，会发现自动多了「提交总览」「审题卡内容」两个分页（内容已被自测清空，正常）。

❌ 如果执行记录是红字报错，先停下来，把红字截图给我。

---

## 步骤五：部署成网址

1. 右上角蓝色按钮 **部署** → **新增部署作业**
2. 左边有个齿轮图示 **选取类型**，点它 → 选 **网页应用程式**
3. 中间三格这样填：
   - 说明：`v1`
   - 执行身分：**我**
   - 具有存取权的使用者：**所有人** ← **这一格最重要，一定要选「所有人」**
4. 点 **部署**
5. 出现一个网址，长这样：
   ```
   https://script.google.com/macros/s/AKfycb.........../exec
   ```
   点旁边的 **复制** 图示

⚠️ 一定要是 **`/exec`** 结尾。如果是 `/dev` 结尾，那是测试网址，学生用不了。

---

## 步骤六：把网址填进 config.js

1. 用记事本打开 `xiezuo/config.js`
2. 找到最上面这几行：
   ```
   API: "",
   ```
3. 把网址贴进两个引号中间：
   ```
   API: "https://script.google.com/macros/s/AKfycb.../exec",
   ```
   引号和最后的逗号都要留着
4. 存档
5. 照 `01-upload-to-github.md` 的**步骤三**，把改好的 `config.js` 重新传上 GitHub 并合并
   （上传时它会问要不要覆盖，选覆盖）

---

## 步骤七：验收

1. 手机或 iPad 开 `你的网址/xiezuo/shequ-wenqing/`
2. 填姓名「测试」、班级「999」
3. 一路做到最后（口令查教师总控台）
4. 结果页出现时，下方应该跳出绿色的 **✓ 已交给老师**
5. 回 Google 表格，「提交总览」应该多一行、「审题卡内容」多几行

**都对了就完成了。**

---

## 步骤八（选做但强烈建议）：加名单，让学生不必打字

《对不起朋友》第二页是「点班级 → 点姓名」登录的。
后台没名单的话，学生要自己打名字——iPad 打字慢，一班 40 人会拖掉五分钟。

1. 回 Google 表格，最下方点 **+** 新增一个分页
2. 把分页改名为：**名单**（两个字，不要多空格）
3. 第一列填四个栏名，依序：`班级` `学号` `姓名` `组别`
4. 从第二列开始填学生，例如：

   | 班级 | 学号 | 姓名 | 组别 |
   |---|---|---|---|
   | 201 | 01 | 陈思 | 1 |
   | 201 | 02 | 李明 | 1 |
   | 202 | 11 | 张浩 | |

   组别可以留空。

**不必重新部署**，存好就生效。学生下次开第二页，就会看到班级和姓名按钮可以点。

---

## 怎么看学生交上来的东西

1. 在你自己电脑上，**双击** `teacher-only/teacher-board.html`
2. 上方填后台网址（`/exec` 那一串）和你的教师密码
3. 点 **载入**

看板有两个分页：
- **提交总览**：谁交了、几点交的、三个过程数字。**「看了答案」次数多的同学，讲评时优先叫。**
- **审题卡内容**：每个人写的中心、选材、核心片段全文

右上角 **导出 CSV** 可以下载存档。
下次上课前记得先导出备份，再用 **清空所选班级的记录**（清空不会删掉名单）。

## 常见问题

**「上传失败，请截图交给老师」**
八成是第五步「具有存取权的使用者」没选「所有人」。
回 Apps Script → 部署 → **管理部署作业** → 铅笔图示 → 改成「所有人」→ 部署。

**改了 Code.gs，但没有生效**
Apps Script 改完程序，必须：部署 → 管理部署作业 → 铅笔图示 → 版本选 **新版本** → 部署。
只按 Ctrl+S 存档是不会更新线上版本的。**这是最容易踩的坑。**

**表格里有人交了两次**
两笔都会留着，这是刻意的——你看得到他改了什么。
看板里同一个人出现两次，看时间最晚的那一笔。
