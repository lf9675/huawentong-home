04　华文通首页「写」区块　加入作文审题的入口
════════════════════════════════════════════════════════

做完前面三步，网址已经能用了，但首页上还看不到入口。
这一步是让「写」区块多出一张卡，点得进去。


── 先做这件事（很重要）─────────────────────────

不要直接抄下面的代码贴进去。先看你首页原本长怎样：

1. GitHub 开 huawentong-home → 点 index.html → 右上角铅笔图示（Edit）
2. 按 Ctrl+F，搜 "写" 或搜你现有工具的名字（例如 grade-comp）
3. 找到「写」区块里**已经有的一张卡**，把那一整段复制下来

那一段就是你的卡片长相。照它改，样式才会跟旁边一致。


── 要改的只有三个地方 ───────────────────────────

把复制来的那一段贴在同一区块里，然后改：

  ① 链接网址  href="..."          →  改成  href="./xiezuo/"
  ② 卡片标题                       →  改成  作文审题互动单
  ③ 卡片说明文字                   →  改成  下面「建议文案」里的句子


── 建议文案（照抄即可）──────────────────────────

  标题：作文审题互动单
  说明：动笔前先想清楚题目要什么。六篇情境记叙文，圈关键词、
        定中心、选材、排详略，做完生成自己的审题卡。

字数比旁边的卡长的话，砍成一句也行：

  说明：六篇情境记叙文的写前审题，做完生成个人审题卡。


── 如果你想直接用现成的（找不到原本的卡片时）──────

下面这段是照「墨金」样式写的，朱红色对应「写」区块。
贴进「写」区块的卡片列表里，位置和其他卡并排：

<a class="tool-card" href="./xiezuo/">
  <span class="tool-name">作文审题互动单</span>
  <span class="tool-desc">六篇情境记叙文的写前审题，做完生成个人审题卡</span>
</a>

⚠️ 前提是你首页的卡片 class 就叫 tool-card / tool-name / tool-desc。
   不一样的话，改成你自己的名字，否则样式会跑掉。


── 教师入口要不要放上去？────────────────────────

建议：不要。

教师总控台有 36 个口令，看板能看到全班作答，
放在首页学生迟早会点到。这两个档留在你自己电脑上双击开就好。

真的想要一个入口，放在「备」区块，而且**不要**写成
「教师总控台」这种一看就想点的名字。


── 改完怎么上传 ──────────────────────────────

如果你是用 GitHub 网页的铅笔图示直接改 index.html：

1. 改完往下滚，Commit message 填：首页加入作文审题入口
2. 选 Commit directly to the feat/xiezuo branch
   （或者你已经合并过了，就直接选 main）
3. 点 Commit changes
4. 若是在分支上改，照 01 文件的步骤四合并到 main


── 验收 ────────────────────────────────────

1. 开你的华文通首页
2. 进「写」区块
3. 应该看到新的一张卡，点下去进到作文审题目录页
4. 手机上也看一次，卡片不该挤在一起或跑版


── 出问题怎么办 ──────────────────────────────

卡片样式跑掉、或首页整个乱了：
去 GitHub 那个合并的 Pull Request 页面 → 滚到最下面 → 点 Revert
→ 建立并合并还原的 PR，约 2 分钟回到原样，历史完整保留。

点下去 404：
检查 href 是不是写成 "./xiezuo/"（前面有 ./，最后有 /）。
写成 "xiezuo" 或 "/xiezuo" 在某些情况会找不到。
