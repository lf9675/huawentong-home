# 00　先读我：这一包有什么、放哪里

## 一句话

六篇作文审题互动单，已整理成可以直接并进「华文通」的 `/xiezuo/` 目录，
另加 Google 表格审题卡汇总后台 ＋ AI 审题诊断 ＋ 教师总控台和看板。

---

## 两个文件夹，去处完全不同

### 📁 `xiezuo`　→　**上传到网站**

```
xiezuo/
├── index.html          学生目录页（学生只需要这一个网址）
├── config.js           ★ 全站唯一要改的设定档
├── hook.js             平台挂钩（自动上传 ＋ AI 按钮）
├── duibuqi-pengyou/    《对不起朋友》　　　中二
├── chenmo-zeren/       《沉默却负责》　　　中二
├── jianchi-kanfa/      《坚持自己的看法》　中二
├── neixiang-gongxian/  《内向也能贡献力量》中一
├── zhiding-jihua/      《制定计划的重要性》中一
└── shequ-wenqing/      《社区的温情》　　　中一
```

每个作文文件夹里固定三个名字：`index.html`（第一页）、`page2.html`（第二页）。
学生网址会长这样，短、干净、念得出来：

```
你的网址/xiezuo/                        ← 给学生的总入口
你的网址/xiezuo/shequ-wenqing/          ← 单篇直接进
```

### 📁 `teacher-only`　→　**留在你自己的电脑，绝对不要上传**

```
teacher-only/
├── teacher-console.html   教师总控台：六篇共 36 个停靠点口令
├── teacher-board.html     教师看板：看全班审题卡、导 CSV、按班清空
├── Code.gs                贴进 Google Apps Script 的后台程序
└── notes/                 六篇的教学重点（详略安排、常见跑题）
```

**为什么不能上传**：总控台上有全部口令，学生看到就能一路跳到底，
「停下来讨论」的设计就废了。看板则可以看到别人的作答。

> 档名全部用英文，是因为中文档名在 Windows 解压后会变乱码。
> 每个档打开后第一行都写了中文标题，不会认错。

## 装机顺序（照这个顺序做，不会卡住）

1. **`01-upload-to-github.md`** — 先把 `xiezuo` 传上去，让网页能开。**先做这一步，其余都可以晚点补。**
2. **`02-google-sheets-backend.md`** — 学生的审题卡自动汇总到你的表格。
3. **`03-connect-ai.md`** — 加上 AI 审题诊断按钮。
4. **`04-homepage-card.txt`** — 在华文通首页「写」区块加两张卡，让人点得进来。

每做完一步，网页都是可用的。第 2、3 步没做，学生照样能做题，只是要自己打印或截图给你。

## 这次动过你原本的文件哪些地方

我**没有改动**六套网页的任何原有程序码，只做了四件事：

1. 文件改名（中文名 → 英文名），并同步改好页面里互相跳转的链接
2. 每页 `<head>` 加一行 `<script src="../config.js">`、页尾加一行 `<script src="../hook.js">`
3. **重新生成全部 36 个口令**——原本《制定计划》和《内向也能贡献力量》口令一模一样，《坚持自己的看法》也撞了一个，同一周教两篇会出事
4. 《对不起朋友》三处：过期的 `deepseek-chat` 改成读设定档、后台网址改成读设定档、存储键改成 `duibuqi-pengyou-v1`（原本叫 `zuowen-shenti-v1`，太通用，做第七篇会互相覆盖）

**万一网页出问题**：把页尾那一行 `<script src="../hook.js"></script>` 删掉，
一切就回到你原本的样子。这是刻意这样设计的。

## 加第七篇作文的时候

只做两件事，不必改任何程序：

1. 把新的两个 HTML 放进 `xiezuo/新代号/`，改名成 `index.html` 和 `page2.html`
2. 打开 `config.js`，照抄一段前面的作文资料改内容

上传后，学生目录页会**自动**多出一张卡，不用手动加。
