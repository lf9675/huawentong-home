材料议论文 V3.1 优化标准
====================

学生端固定流程
1. 三题首页：只显示学生需要的入口，不显示母版或教师开发信息。
2. 审题：认题型 → 关键词 → 材料明说/合理推出 → 选中心论点 → 诊断失分点 → 90秒提纲。
3. 范文：写前路线 → 学习版四块 PEEL → 考试版完整段落 → 结构地图 → 自检。

教学原则
- 材料明确给出的方向必须回应；合理延伸要明确标示为“推论”，避免学生把老师的结构误当成材料原文。
- 一般程度学生以三个分论点为主，先写清楚再追求多。
- 例子短写，分析详写；每段必须回答“例子说明什么”。
- 范文不是背诵文本；学习版负责看结构，考试版负责看成文效果。
- 题目、材料、范文正文使用楷体；教学解析使用宋体。
- 难词英文只按需显示；语音解释按需使用。
- iPad 竖屏 768px 下，PEEL 地图必须改为纵向，不硬塞四列。
